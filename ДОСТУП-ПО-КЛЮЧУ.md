# 🔑 Искра: доступ по ключу на 24 часа

Коротко: у каждого пользователя есть **код клиента** — он постоянный. Ключ выдаёт владелец
в Telegram, ключ привязан к коду клиента и включает **Pro на 24 часа с момента активации**.
Бесплатная версия работает как раньше, ключ только добавляет Pro-возможности.

---

## 1. Код клиента

Формат ровно как договаривались — **18 знаков в трёх группах**:

```
123456-AB12CD-orange
└─┬──┘ └──┬─┘ └──┬─┘
 6 цифр  6 латинских букв/цифр   слово из 6 английских букв
```

- Генерируется сам при первом открытии Искры и хранится в браузере **навсегда**.
- Первые 12 знаков не повторяются (в браузере ведётся список выданных).
- Слова берутся из встроенного списка английских слов по 6 букв, повторы слов разрешены.
- Код показан в двух местах: **шапка → плашка «Бесплатная / Pro»** и **⚙ → «Получить ключ на 24 часа»**.
- Там же кнопки: «Скопировать», «Написать в Telegram» (готовое сообщение с кодом),
  «У меня есть другой код» — чтобы перенести доступ на новое устройство.

> Важно: код — это фактически логин. Кто знает код, тот может пользоваться выданным на него ключом.
> Показывать его можно только владельцу Искры.

---

## 2. Ключ

Формат (серверный):

```
ISKRA-24-1A2B-3C4D-5E6F
```

- Одноразовый: активируется один раз и навсегда привязывается к коду клиента.
- Действует **24 часа с момента первой активации** (время хранит сервер, перевод часов на устройстве не помогает).
- Продлить нельзя «наполовину»: новый ключ заменяет старый.
- Есть ключи на любой срок: `key <код> 720` — это 30 дней (подписка Pro за 450 ₽).

Цены (меняются в одном месте — `ACCESS.price24` и `PAY_PRICE_RUB` в `index.html`):

| Что | Сколько |
|---|---|
| Ключ на 24 часа | **99 ₽** |
| Pro на 30 дней | **450 ₽** (или ~4.6 TON по курсу) |

---

## 3. Как пользователь получает ключ

1. Открывает Искру → плашка доступа → копирует свой код клиента.
2. Жмёт «Написать в Telegram» — открывается чат с владельцем, сообщение уже заполнено:
   `Привет! Хочу ключ Искры на 24 часа. Мой код клиента: 123456-AB12CD-orange`.
3. Оплачивает, владелец генерирует ключ и присылает его.
4. Вставляет ключ в поле «Ввести ключ» → «Активировать». Pro включается сразу, в шапке
   появляется «Pro · 23 ч 59 мин».

Ограничения по времени проверяются каждые 30 секунд: когда ключ кончился, Искра сама
возвращается в бесплатную версию и пишет об этом.

## 4. Настройка сервера (делается один раз, ~3 минуты)

Ключи проверяются в твоём Supabase, без отдельного сервера.

1. Открой [supabase.com](https://supabase.com) → свой проект (адрес уже вписан в `index.html`).
2. Слева **SQL Editor** → **New query**.
3. Открой файл [`supabase/iskra-access.sql`](supabase/iskra-access.sql), замени
   `ПАРОЛЬ-ВЛАДЕЛЬЦА` на свой длинный пароль (20+ символов) и вставь весь текст в редактор.
4. Нажми **Run**. Внизу должно появиться `{"ok": true, "version": 1}`.
5. В Искре открой консоль: напиши в чат `/console`, введи пароль владельца (локальный),
   потом команду:
   ```
   secret твой-пароль-из-sql
   ```
6. Проверка:
   ```
   key24 123456-AB12CD-orange тест
   ```
   Должен появиться ключ вида `ISKRA-24-XXXX-XXXX-XXXX`.

Если сервер не настроен, экран ключа честно пишет «Сервер ключей не настроен», а Искра
всё равно может выдавать **офлайн-ключи** `ISKRA-L-…` (команда `key24 --local <код>`).
Офлайн-ключ подписывается секретом внутри файла: он работает без сервера, живёт
7 дней на активацию и 24 часа с момента активации, но его теоретически можно подделать,
если разобрать код. Поэтому основной режим — серверный.

## 5. Команды владельца в `/console`

| Команда | Что делает |
|---|---|
| `myclient` | показать свой код клиента |
| `secret <пароль>` | сохранить пароль владельца (тот же, что в SQL) |
| `key24 <код> [название]` | выдать ключ на 24 часа |
| `key24 --local <код> [название]` | выдать офлайн-ключ на 24 часа |
| `key <код> <часы> [название]` | ключ на любое число часов (720 = 30 дней) |
| `keys` | список ключей: ключ, код клиента, название, срок, статус |
| `revoke <ключ>` | отозвать ключ |
| `access <код>` | проверить, есть ли у человека активный доступ |
| `pay` | реквизиты для оплаты |

Пример выдачи:

```
key24 482913-K7M2QX-orange Маша, сутки
```

## 6. Что именно открывает ключ

- Картинки в высоком качестве
- Генерацию видео
- Любые языки (в бесплатной — только русский и английский)
- Свободный стиль и крепкие выражения (по желанию)
- Всё остальное, что умеет бесплатная версия

Бесплатная версия не урезана: чат, учёба, код, тексты, задачи и домашка работают без ключа.

## 7. Честно о защите

Приложение целиком работает в браузере, поэтому любые ограничения на стороне клиента
можно обойти, если очень захотеть. Что сделано, чтобы это было неинтересно:

- ключи и время активации хранятся **на сервере**, а не в браузере;
- ключ одноразовый и привязан к коду клиента;
- пароль владельца лежит в таблице, закрытой RLS: через публичный API его не прочитать;
- выдать ключ можно только зная пароль владельца.

Что остаётся: человек может подменить файл `index.html` у себя и «включить» Pro локально.
На реальные деньги это не влияет: без серверного ключа доступ не появится ни у кого другого,
а платить или нет — его выбор. Полная защита возможна только с настоящим бэкендом,
который сам ходит в модели; это следующий шаг, если понадобится.

## 8. Если снова вылезет Puter

Раньше при отправке сообщения открывалось окно регистрации Puter и проверить ИИ было нельзя.
Теперь так:

- если вход в Puter есть — Искра работает через Puter;
- если входа нет — **молча** отвечает бесплатным движком (Pollinations/llm7), без окон;
- в настройках появилась кнопка **«Проверить ИИ»**: она отправляет живой запрос выбранной
  модели и показывает зелёным/оранжевым, что именно работает.

Войти в Puter по-прежнему можно вручную: ⚙ → «Войти в Puter» (это необязательно).
