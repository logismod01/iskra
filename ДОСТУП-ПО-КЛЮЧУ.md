# 🔑 Искра: доступ по ключу (4 тарифа)

Коротко: **код клиента есть только у зарегистрированного аккаунта**, и он постоянный.
Гостю код не создаётся: без аккаунта нет ни тарифов, ни активации ключа. Ключ выдаёт владелец
в Telegram, ключ привязан к коду клиента и включает **Pro с момента активации**.
Тарифов четыре: **24 часа · месяц · год · навсегда**. Бесплатная версия работает как раньше,
ключ только добавляет Pro-возможности.

---

## 1. Код клиента

Формат ровно как договаривались — **18 знаков в трёх группах**:

```
123456-AB12CD-orange
└─┬──┘ └──┬─┘ └──┬─┘
 6 цифр  6 латинских букв/цифр   слово из 6 английских букв
```

- Создаётся после регистрации аккаунта и хранится в браузере **навсегда**.
  До регистрации панель «Искра Про» показывает только одно: «У вас нет аккаунта — зарегистрируйтесь».
- Первые 12 знаков не повторяются (в браузере ведётся список выданных).
- Слова берутся из встроенного списка английских слов по 6 букв, повторы слов разрешены.
- Код показан в двух местах: **шапка → плашка «Бесплатная / Pro»** и **⚙ → «Получить ключ на 24 часа»**.
- Там же кнопки: «Скопировать», «Написать в Telegram» (готовое сообщение с кодом),
  «У меня есть другой код» — чтобы перенести доступ на новое устройство.

> Важно: код — это фактически логин. Кто знает код, тот может пользоваться выданным на него ключом.
> Показывать его можно только владельцу Искры.

## 2. Ключ

Формат (серверный):

```
ISKRA-24-1A2B-3C4D-5E6F
```

- Одноразовый: активируется один раз и навсегда привязывается к коду клиента.
- Срок идёт **с момента первой активации** (время хранит сервер, перевод часов на устройстве не помогает).
- Продлить нельзя «наполовину»: новый ключ заменяет старый.
- «Навсегда» выдаётся только с сервера — офлайн-ключ на 0 часов не создаётся намеренно.

### Тарифы и цены

| Тариф | id | Срок | Цена |
|---|---|---|---:|
| 24 часа | `day` | 24 часа (24 ч) | **99 ₽** |
| Месяц | `month` | 30 дней (720 ч) | **450 ₽** (~4.6 TON) |
| Год | `year` | 365 дней (8760 ч) | **3490 ₽** |
| Навсегда | `forever` | без срока, один платёж | **7990 ₽** |

Цены хранятся в браузере владельца (`localStorage["iskra.prices.v1"]`) и меняются **без правки кода**:

```
price month 590            → поменять цену одного тарифа
prices 99 590 3990 8990    → поменять все четыре сразу (день месяц год навсегда)
plans                      → посмотреть текущие тарифы и цены
pay                        → реквизиты и таблица тарифов
```

По умолчанию в коде (`ACCESS_PLANS`) лежат 99 / 450 / 3490 / 7990 ₽ — чтобы новые цены
увидели все покупатели, поменяй их там (это одна строка) или продиктуй владельцу точные цены.

## 3. Как пользователь получает ключ

1. Открывает Искру → плашка доступа → копирует свой код клиента.
2. Жмёт «Написать в Telegram» — открывается чат с владельцем, сообщение уже заполнено:
   `Привет! Хочу ключ Искры на 24 часа. Мой код клиента: 123456-AB12CD-orange`.
3. Оплачивает, владелец генерирует ключ и присылает его.
4. Вставляет ключ в поле «Ввести ключ» → «Активировать». Pro включается сразу, в шапке
   появляется «Pro · 23 ч 59 мин».

Ограничения по времени проверяются каждые 30 секунд: когда ключ кончился, Искра сама
возвращается в бесплатную версию и пишет об этом.

## 4. Настройка сервера (делается один раз, ~3 минуты)

Ключи проверяются в твоём Supabase, без отдельного сервера.

1. Открой [supabase.com](https://supabase.com) → свой проект (адрес уже вписан в `index.html`).
2. Слева **SQL Editor** → **New query**.
3. Открой файл [`supabase/iskra-access.sql`](supabase/iskra-access.sql), замени
   `ПАРОЛЬ-ВЛАДЕЛЬЦА` на свой длинный пароль (20+ символов) и вставь весь текст в редактор.
4. Нажми **Run**. Внизу должно появиться `{"ok": true, "version": 1}`.
5. В Искре открой консоль: напиши в чат `/console`, введи пароль владельца (локальный),
   потом команду:
   ```
   secret твой-пароль-из-sql
   ```
6. Проверка:
   ```
   key24 123456-AB12CD-orange тест
   ```
   Должен появиться ключ вида `ISKRA-24-XXXX-XXXX-XXXX`.

Если сервер не настроен, экран ключа честно пишет «Сервер ключей не настроен», а Искра
всё равно может выдавать **офлайн-ключи** `ISKRA-L-…` (команда `key24 --local <код>`).
Офлайн-ключ подписывается секретом внутри файла: он работает без сервера, живёт
7 дней на активацию и 24 часа с момента активации, но его теоретически можно подделать,
если разобрать код. Поэтому основной режим — серверный.

## 5. Свой ключ доступа к движкам (необязательно)

Ключ Pro и ключ движков — разные вещи, они не связаны. Без любого из них Искра отвечает
своими бесплатными движками. Если человек вписал свой ключ в ⚙ → «Искра» → «Свой ключ доступа»,
Искра сама понимает его вид (`gsk_`, `hf_`, `sk-or-…`) и отвечает через него первой:
быстрее и без общих лимитов. Названий сервисов в интерфейсе нет — для человека это всё Искра.

## 6. Один аккаунт — один код — один ключ

- Код клиента создаётся один раз и **не меняется**: кнопки «У меня есть другой код» больше нет.
- Код привязан к аккаунту: если в одном браузере два аккаунта, у каждого свой код и свой ключ.
- С одного IP можно создать **не больше двух аккаунтов** — значит, и не больше двух ключей.
  Третий аккаунт с того же адреса программа не даст создать.
- На сервере это же правило проверяет функция `iskra_issue_key`: если у кода уже есть активный
  (не отозванный и не истёкший) ключ, второй она не выдаст. Нужен второй ключ на тот же код —
  только осознанно, с флагом:

```
key 123456-AB12CD-word month --force
```

## 5.1. Почта, пароль и Google

- Регистрация по почте и паролю создаёт аккаунт **сразу**, письмо подтверждения больше ничего не блокирует.
- Вход по коду: если письмо от Supabase не пришло (их бесплатная почта отправляет 2–3 письма в час),
  на экране всегда показан шестизначный код — он действует и пускает в аккаунт этого браузера.
- Google и GitHub: аккаунт создаётся в момент нажатия кнопки. Если провайдер в Supabase включён,
  следом открывается настоящее окно входа и серверный id просто дописывается в уже созданный аккаунт.

## 5.2. Команды владельца в `/console`

### Вход запоминается
Первый раз пароль владельца вводится в `/console` и сохраняется только как SHA-256-хеш.
После удачного ввода Искра запоминает **этот браузер на 30 дней** — при следующем открытии консоль
сразу пишет «Владелец узнан» и пароль не спрашивает. Токен привязан к хешу пароля, поэтому
команда `pass <новый пароль>` мгновенно убивает все старые запоминания.

Чтобы запереть насовсем (например, на чужом компьютере): команда `lock` — она стирает токен
и снова спрашивает пароль. Пять неверных попыток по-прежнему дают паузу 60 секунд.



| Команда | Что делает |
|---|---|
| `myclient` | показать свой код клиента |
| `secret <пароль>` | сохранить пароль владельца (тот же, что в SQL) |
| `key24 <код> [название]` | выдать ключ на 24 часа |
| `key24 --local <код> [название]` | выдать офлайн-ключ на 24 часа |
| `key <код> day\|month\|year\|forever [название]` | ключ по тарифу |
| `key <код> <часы> [название]` | ключ на любое число часов (720 = 30 дней) |
| `plans` | таблица тарифов и цен |
| `price month 590` | поменять цену тарифа |
| `prices 99 450 3490 7990` | поменять все цены сразу |
| `keys` | список ключей: ключ, код клиента, название, срок, статус |
| `revoke <ключ>` | отозвать ключ |
| `access <код>` | проверить, есть ли у человека активный доступ |
| `pay` | реквизиты для оплаты |
| `rates` | курсы звёзд, USDT и TON и цены тарифов в них |
| `rate star 1.4` | поправить курс (`star` / `usdt` / `ton`) |
| `lock` | стереть запоминание входа и запереть консоль |
| `pass <новый пароль>` | сменить пароль владельца (старые запомненные входы перестают действовать) |

Пример выдачи:

```
key 482913-K7M2QX-orange month Маша, месяц
key 482913-K7M2QX-orange forever Подарок
key24 482913-K7M2QX-orange Маша, сутки
```

## 6. Что именно открывает ключ

- Картинки в высоком качестве: Flux / gpt-image-2, стили (фото, арт, аниме, 3D, минимал),
  форматы 1:1 / 16:9 / 9:16 / 4:3 и три уровня детализации
- Видео: короткие ролики по описанию на открытой модели в браузере, без регистрации
- **3D-мастерская**: фигуры и модели по параметрам, превью, `.obj` и готовый скрипт для Blender
- Режим «Blender» в меню помечен Pro: без ключа он не включается (объяснить про Blender в чате можно всегда)
- Любые языки (в бесплатной — только русский и английский)
- Свободный стиль и крепкие выражения (по желанию)
- Всё остальное, что умеет бесплатная версия

Бесплатная версия не урезана: чат, учёба, код, тексты, задачи и домашка работают без ключа.

## 7. Честно о защите

Приложение целиком работает в браузере, поэтому любые ограничения на стороне клиента
можно обойти, если очень захотеть. Что сделано, чтобы это было неинтересно:

- ключи и время активации хранятся **на сервере**, а не в браузере;
- ключ одноразовый и привязан к коду клиента;
- пароль владельца лежит в таблице, закрытой RLS: через публичный API его не прочитать;
- выдать ключ можно только зная пароль владельца;
- вход в консоль запоминается токеном в этом браузере (30 дней) и стирается командой `lock`.

Что остаётся: человек может подменить файл `index.html` у себя и «включить» Pro локально.
На реальные деньги это не влияет: без серверного ключа доступ не появится ни у кого другого,
а платить или нет — его выбор. Полная защита возможна только с настоящим бэкендом,
который сам ходит в модели; это следующий шаг, если понадобится.

## 8. Если Искра молчит

Вход и регистрация в сторонних сервисах больше не нужны: у Искры свои бесплатные движки,
и она перебирает их молча.

- Если один движок занят — берётся следующий, окно входа не открывается.
- Если заняты все — Искра отвечает из базы знаний, а в карточке пишет настоящую причину.
- Кнопка **«Проверить Искру»** (⚙ → «Искра» → «Проверить Искру») отправляет живой вопрос
  и показывает зелёным/оранжевым, что именно работает.
- Свой ключ доступа — по желанию: он просто снимает общий лимит.

## 7. Что изменилось в 1.6

- **Код клиента — только у аккаунта.** Гость не получает код, не видит тарифы и не может активировать ключ:
  вместо этого панель Pro предлагает зарегистрироваться.
- **Консоль не выдаёт Pro гостям.** Команды `pro`, `mat on`, `key`, `key24`, `keys`, `revoke`, `access`
  без аккаунта отвечают: «У вас нет аккаунта — зарегистрируйтесь». Из консоли владелец по-прежнему
  выпускает ключи на коды клиентов покупателей — но только когда сам вошёл в аккаунт.
- **Бейджи Pro исчезают сразу после активации ключа** — режимы, меню режимов, кнопка 3D-мастерской
  и панель тарифов перерисовываются без перезагрузки страницы.
- **Запрос не теряется при обновлении страницы.** Если перезагрузить Искру, пока она думает,
  запрос остаётся в чате, ответ помечается как прерванный, появляется кнопка «Повторить»,
  а переключатель веб-поиска и черновик в поле ввода сохраняются.
