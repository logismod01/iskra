# Sye — агент на рабочем столе

**Sye** (Сью) — виртуальный агент для Windows: не чат, а исполнитель. Он читает файлы проекта,
находит баги и правит код, запускает тесты и сборку, ищет по документации в интернете и
разбирает скриншот экрана, если человек показал проблему картинкой.

Приложение на Electron: окно с журналом шагов + значок в трее + горячие клавиши.

| Действие | Клавиши |
|---|---|
| Снимок экрана и новая задача | `Ctrl+Alt+S` |
| Показать окно | `Ctrl+Alt+Space` |
| Отправить задачу | `Enter` (новая строка — `Shift+Enter`) |
| Остановить | кнопка «Стоп» в окне |

## Что внутри

```
main.js          главный процесс: окно, трей, горячие клавиши, файлы, терминал, снимок экрана
preload.js       мост window.sye — у окна нет прямого доступа к Node
core/agent.js    цикл задачи: думаю → действую → смотрю результат → снова думаю
core/protocol.js разбор ответа модели (<action>, <final> и их варианты)
core/tools.js    12 инструментов: файлы, терминал, интернет, скриншот
core/guard.js    что можно, что опасно, что запрещено навсегда
core/license.js  подписка Pro, привязка к устройству, ограниченный режим
core/keys.js     те же ключи, что у сайта Искры (офлайн и серверные)
core/engines.js  бесплатные движки + свой ключ, если человек его ввёл
renderer/        окно: тёмная тема, лента шагов, настройки, активация
assets/          иконки приложения и трея
test/            87 проверок на встроенном node --test
```

## Установка и сборка

```bash
cd agent
npm install
npm start          # запустить приложение
npm test           # 87 проверок, Electron не нужен
npm run dist       # собрать установщик под текущую систему
```

Сборка для Windows на Linux/macOS:

```bash
npx electron-builder --win nsis portable
```

Готовые файлы — в `agent/dist/`:

- `Iskra Agent Setup 0.1.0.exe` — установщик (можно выбрать папку, ярлык на рабочем столе);
- `Iskra Agent 0.1.0.exe` — portable, запускается без установки.

Если не хочется ставить Electron: **GitHub → Actions → «Sye — сборка для Windows» → Run workflow**.
Сборка сама прогонит тесты, соберёт `.exe` на `windows-latest` и положит файлы в Artifacts
(`Sye-Windows`, хранится 14 дней). То же запускается на тег `agent-v*`.

## Подписка

- Без ключа Pro агент не работает: при первом запуске открывается окно активации, закрыть его нельзя.
- Ключ привязывается к компьютеру (sha256 от имени машины, системы, архитектуры и пользователя).
  Второй компьютер с тем же ключом увидит «Ключ уже занят другим компьютером».
- Когда Pro заканчивается, Sye остаётся, но «работает плохо»: **2 шага** на задачу,
  чтение файлов и ответы — без терминала, без записи и удаления файлов, без интернета,
  без разбора скриншотов, короткий лимит ответа.
- Ключи те же, что у сайта: `ISKRA-24-XXXX-XXXX-XXXX` (сервер, проверяется через Supabase)
  и офлайн `ISKRA-L-…` (активируется в течение 7 дней после выдачи).
- Сверка подписки с сервером — раз в 6 часов; кнопка «Проверить» в настройках делает это сразу.

## Уровни доступа

Выбираются в ⚙ в окне агента:

| Уровень | Поведение |
|---|---|
| `ask` — «Спрашивать всё» | подтверждение на каждую запись файла и команду |
| `folder` — «Свободно в папке» | по умолчанию: внутри рабочей папки сам, опасное — с подтверждением |
| `full` — «Полный доступ» | можно за пределы папки; системные команды всё равно запрещены |

Системные папки (`C:\Windows`, `Program Files`, `/etc`, `/usr/bin`, `~/.ssh`, `~/.config`)
считаются рискованными при любом уровне: запись и удаление там требуют подтверждения,
а удаление запрещено совсем.

## Безопасность

**FORBIDDEN — не выполняется никогда, даже с подтверждением:**

- удаление корня (`rm -rf /`, `rm -rf ~`, `rmdir /s /q C:\`), `format`, `diskpart`, `bcdedit`, `dism`;
- правка `HKLM`/`HKEY_LOCAL_MACHINE`;
- `shutdown`, `reboot`, `poweroff`, `halt`;
- `dd if=…`, `mkfs`, `fdisk`, `parted /dev/…`;
- «бомба» процессов `:(){ :|:& };:`;
- `curl … | sh`, `wget … | bash`, `powershell -enc …`;
- `sudo`, `runas`, `su`, `doas`;
- убийство `explorer`/`winlogon`/`csrss`/`lsass`, `kill -9 1`;
- обратные шеллы (`nc host port`, `/dev/tcp/…`).

**RISKY — спрашиваем, если уровень не `full`:** удаление файлов, `git reset --hard`,
`git push -f`, установка пакетов (`npm/pip/winget`), `curl -o`, правка реестра, службы,
`taskkill`, перенос файлов в системные папки.

Дополнительно:

- рабочая папка — жёсткая рамка: `..` и абсолютные пути наружу отсекаются, пока не включён `full`;
- текст из файлов, сайтов и скриншотов считается **данными**, а не командами — модель обязана
  сообщать о «выполни…», а не выполнять;
- секреты (`sk-…`, `gsk_…`, `ISKRA-…`, длинные токены) вырезаются из всего, что попадает в журнал;
- ссылки на `localhost`, `127.0.0.1`, `192.168.*`, `*.local` не открываются;
- в окне выключены `nodeIntegration` и навигация: внешние ссылки уходят в системный браузер.

## Экран и скриншоты

`Ctrl+Alt+S` делает снимок, открывает окно и подставляет картинку в задачу — можно сразу
написать «почему тут ошибка?». Снимок передаётся в задачу вместе с текстом и уходит в движок
со зрением (`screen.look`). На macOS 14+ система спросит разрешение на запись экрана;
на Windows снимок делает сам Electron, разрешение не нужно.

## Настройки

Хранятся в `%APPDATA%/Iskra Agent/` (`sye-settings.json`, `sye-license.json`, `sye-history.json`).

| Поле | Что значит |
|---|---|
| `access` | уровень доступа (`ask` / `folder` / `full`) |
| `workspace` | рабочая папка |
| `apiKey`, `apiBase`, `apiModel` | свой ключ и адрес движка (необязательно; если задан — идёт первым) |
| `lastTask` | последняя задача |
| `seenTrayHint` | показывали ли подсказку про трей |

## Тесты

```bash
npm test     # или из корня репозитория: npm run test:agent
```

| Файл | Проверяет |
|---|---|
| `test/protocol.test.cjs` | `<final>`, `<action>`, ```action```, ```json```, голый JSON, неизвестный инструмент, обязательные аргументы |
| `test/guard.test.cjs` | запрещённые команды, опасные команды, уровни доступа, выход из папки, вырезание секретов |
| `test/keys.test.cjs` | формат кода клиента, офлайн-ключ, чужая подпись, просрочка, распознавание типов ключей |
| `test/license.test.cjs` | активна / закончилась / нет / чужое устройство, дни, лимиты, активация, деактивация |
| `test/tools.test.cjs` | запись → чтение → замена → поиск, отказ при `expired`, подтверждения, терминал, интернет, скриншот |
| `test/agent.test.cjs` | цикл действия, наблюдение для модели, подсказка при неверном формате, `task.done`, конец шагов, остановка, падение движка |
| `test/engines.test.cjs` | набор движков, отсутствие лишнего `Authorization`, свой ключ первым, сборка адресов |
| `test/ui.test.cjs` | синтаксис, все `id` на месте, мост preload, тема, горячие клавиши, иконки, отсутствие внешних ссылок |

## Известные ограничения

- Первая версия — **Windows**; сборки для macOS и Linux есть в конфиге, но не проверялись на живых системах.
- Снимок экрана на macOS требует разрешения и может быть пустым при аппаратном захвате.
- Бесплатные движки иногда отвечают медленно или заняты — агент перебирает их по очереди и
  показывает в окне, что «подбирает, кто ответит».
- Своих моделей у агента нет: он работает на тех же бесплатных движках, что и сайт, плюс
  необязательный свой ключ.
