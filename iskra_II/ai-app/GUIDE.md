# ✦ Искра — твой ИИ-ассистент

**Имя:** Искра — короткое, русское, звучит как нейросеть. Образ: огонёк ума, который разгорается.
Запасные варианты, если захочешь сменить: **Вега**, **Заря**, **Луч**.

Меняется в одном месте — первая строка `app.js`:

```js
const BRAND = { name: "Искра", tagline: "..." };
```

## Шаг 1. Получить бесплатный ключ (5 минут)

### Вариант А — Groq (начни с него: быстро, есть зрение)
1. https://console.groq.com → **Sign in** → **Continue with Google**
2. Слева **API Keys** → **Create API Key** → имя `iskra` → **Submit**
3. Скопируй ключ `gsk_...` сразу — второй раз не покажут
4. Модель для фото: `meta-llama/llama-4-scout-17b-16e-instruct`
5. Лимит: 30 запросов/мин

### Вариант Б — OpenRouter (больше моделей)
1. https://openrouter.ai → **Sign in** через Google/GitHub
2. **Keys** → **Create Key** → скопируй `sk-or-v1-...`
3. Бесплатные модели — с `:free` в названии. Лимит 50 запросов/день

> Сделай **оба** ключа. Кончился лимит на одном — переключился за 5 секунд.

## Ошибки и что делать

| Ошибка | Причина и решение |
|---|---|
| `HTTP 401` | Ключ неверный. Вставь заново без пробелов |
| `HTTP 404` | Модель удалили. Выбери другую из списка |
| `HTTP 402` | Кончился лимит. Переключись на Groq или другую `:free` |
| `HTTP 429` | Больше 30 запросов/мин. Подожди 30 секунд |
| `image` / `vision` | Модель не понимает фото. Возьми с иконкой глаза |
| `Failed to fetch` | Нет интернета, или это локальное превью |
| Веб-поиск ругается | Плагин требует баланс на OpenRouter. Выключи глобус |
| Картинка не нарисовалась | Сервер генерации перегружен. Повтори |
| «Память браузера заполнена» | Удали старые чаты |

## ⚡ Навыки — 23 готовые команды
Кнопка **⚡** слева внизу, рядом со скрепкой. Открывается список по категориям:

| Категория | Что там |
|---|---|
| **Учёба** | Объясни тему · Реши задачу · Сделай конспект · Проверь сочинение · План подготовки · Как пятилетнему · Шпаргалка · Переведи · Проверь мои ответы |
| **Код** | Напиши код · Найди ошибку · Объясни код · Упрости · Сделай проект · Собери регулярку |
| **Текст** | Сочинение · Сократи · Перепиши красиво · Пост или письмо |
| **Жизнь** | Составь план · Выбери из вариантов · Разбери ситуацию · Скажи честно |

**Как пользоваться:** написал в поле «теорема Пифагора» → нажал ⚡ → «Объясни тему» → текст сам подставился в готовую команду → Enter. Есть поиск по навыкам.

## 📚 База знаний — Искра отвечает по твоим конспектам
Кнопка **📖** в шапке. Вставляешь текст конспекта (или загружаешь `.txt`) → Искра ищет в нём нужный кусок и отвечает **по нему**, а не по памяти.

**Зачем:** модель не знает твой учебник. Загрузил параграф — и она отвечает по формулировкам из него, а не «в среднем по интернету».

**Как работает:** поиск по ключевым словам (не по смыслу). Чем точнее вопрос — тем лучше находит. Формулируй вопрос теми же словами, что в конспекте.

**Ограничения честно:**
- Работает без всяких платных сервисов, прямо в браузере
- Хранится в localStorage — примерно **5 МБ** на всё. Один параграф ≈ 2–5 КБ, так что влезет много
- Это не «обучение модели»: база подмешивается в каждый запрос как справка

## 🧮 Калькулятор — не врёт в арифметике
Ничего нажимать не надо. Если в вопросе есть вычисление (`12/4`, `156*23`, `3^2+4^2`), точный ответ подставляется в запрос — модель не считает сама, а берёт готовое число.

Проверено: на «мне 14 лет» и «2026 год» не срабатывает, ложных вычислений нет.

## 🔍 Поиск по чатам
Поле над списком чатов в боковой панели. Ищет по названиям — когда чатов станет 50, без него не разберёшься.

## Что по-прежнему НЕ происходит

- ❌ **Модель не «дообучается».** Мозги живут на серверах Groq/OpenRouter, мы к ним только подключаемся. Настоящее дообучение — миллионы рублей и датацентр
- ✅ **Но «знать больше» она может** — через навыки, базу знаний и калькулятор. Этого хватает в 95% случаев

# 🆕 Модели, анимации и что было с ошибкой 405

## ❗ Ошибка 405 — что это было

**405 = «метод не разрешён».** Значит, запрос ушёл **не туда**, куда надо.

Причина: в настройках был выбран провайдер **«Свой URL»** с пустым адресом. Тогда Искра отправляла запрос на твой же сайт (GitHub Pages), а тот не принимает такие запросы.

**Что теперь:**
- Если выбрать «Свой URL» и не вписать адрес — сразу под полем появится красное предупреждение
- При попытке отправить сообщение выскочит понятное объяснение и настройки откроются сами
- 📌 **Решение прямо сейчас:** открой ⚙ → выбери **Groq** или **OpenRouter** → сохрани

## 🤖 Выбор модели: Искра +1 и другие

Нажми на **чип с названием модели** в шапке (там написано «Искра +1») — откроется окно выбора.

| Секция | Что там |
|---|---|
| **Искра** | Наша модель: **Искра +1** (видит фото, быстрая) и **Искра +1 Pro** (сложные задачи, рассуждения) |
| **Бесплатные** | Все свободные модели провайдера, с пометкой «фото» у зрячих |
| **Платные** | Только у OpenRouter — с ценой за 1 млн токенов (нужен баланс на аккаунте) |
| **Своя модель** | Любой id модели вручную |

**Честно про «свою модель»:** Искра +1 — это не отдельная обученная нейросеть (обучить свою в 14 лет за 0 ₽ невозможно). Это **наша сборка**: выбранная лучшая бесплатная модель + наш характер + наши навыки + память + база знаний + калькулятор. Для пользователя это выглядит и работает как своя модель — со своим именем и версией.

## ✨ Анимации и краски

- Логотип и кнопки — живой переливающийся градиент
- Вокруг логотипа дышат светящиеся пятна
- Обстановка на фоне медленно пульсирует
- Сообщения и карточки влетают снизу
- Пилюли режимов подпрыгивают при наведении, активная светится
- В поле ввода при фокусе бежит блик по рамке
- Кнопка отправки пружинит; во время ответа пульсирует кольцом
- Индикатор «печатает» — три прыгающие точки
- **Смена темы = вспышка краски** из точки клика + плавный переход всех цветов
- Точка на чипе модели пульсирует

Если анимации мешают — система сама их выключит, если у тебя в настройках ОС стоит «уменьшить движение».
