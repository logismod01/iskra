Что такое интернет|Сеть сетей, где компьютеры обмениваются пакетами данных по протоколу IP. Нет единого центра. Сайты работают через HTTP, почта — через свои протоколы.|техника интернет сеть
Что такое домен|Имя сайта вроде example.ru, которое переводится в IP-адрес через DNS. Зона .ru означает Россию, но не гарантирует страну сервера. Домен арендуют на срок.|техника домен сайт dns
Как работает поиск в интернете|Роботы обходят страницы, строят индекс, алгоритм ранжирует по релевантности и качеству. Реклама помечена. Плохие запросы дают мусор, поэтому уточняйте слова.|техника поиск интернет
Что такое алгоритм|Конечная последовательность шагов для решения задачи. Без алгоритма не работает ни одна программа. Сортировка и поиск — базовые примеры.|техника алгоритм программирование
Что такое облако|Удалённые серверы, где хранят файлы и запускают программы. Плюс — доступ отовсюду, минус — зависимость от интернета и правила провайдера. Делайте копии.|техника облако хранение
Что такое GPS|Спутниковая навигация: приёмник вычисляет положение по времени сигналов от спутников. Работает на улице, в тоннеле — нет. Сами спутники не передают данные о вас.|техника gps навигация
Что такое 5G|Пятое поколение мобильной связи: выше скорость, меньше задержка. Требует новых станций, радиус меньше. Покрытие зависит от оператора и города.|техника 5g связь
Что такое блокчейн|Цепочка блоков с хешами, где изменение одного блока ломает все следующие. Данные распределены по участникам. Технология не гарантирует правду в записи.|техника блокчейн
Криптовалюта|Цифровые деньги на блокчейне, курс крайне волатилен. Ключи к кошельку — единственный доступ. Нет гарантий возврата при потере. Риск потерь очень высок.|техника криптовалюта
Что такое виртуальная реальность|Шлем создаёт ощущение присутствия в другом мире. VR полностью заменяет картинку, AR добавляет элементы в реальность. Нужны контент и мощность устройства.|техника vr ar
Что такое робот|Машина, которая воспринимает среду и действует по программе. Промышленные роботы собирают, бытовые пылесосят, дроны летают. Автономность растёт, но небезгранична.|техника робот автоматизация
Дрон|Летающий аппарат с дистанционным управлением, часто с камерой. Полёты регулируются законом: регистрация и ограничения по местам. Батарея — слабое место.|техника дрон
3D-печать|Послойное создание объекта из пластика, смолы или металла. Модель готовят в программе. Домашние принтеры печатают медленно.|техника 3d печать
Квантовый компьютер|Использует кубиты и суперпозицию для особых задач, а не «быстрее всё». Пока экспериментальный. Угроза для старых шифров в теории.|техника квантовый компьютер
Большие данные|Огромные массивы, которые обычными способами не обработать. Работают через хранилища и алгоритмы. Данные без качества бесполезны.|техника данные big data
Что такое машинное обучение|Программа находит закономерности в примерах, а не по жёстким правилам. Нужны данные и проверка. Ошибки модели повторяют ошибки выборки.|техника машинное обучение ии
Что такое нейросеть|Много слоёв простых элементов, которые учатся на данных. Хороша для изображений, текста, звука. Не даёт гарантий и может ошибаться уверенно.|техника нейросеть ии
Что такое хеш|Короткий код от данных: любое изменение меняет хеш. Проверяют целостность файлов и пароли. Вернуть данные из хеша нельзя.|техника хеш шифрование
Что такое шифрование|Сокрытие содержимого шифром по ключу. Сайты используют HTTPS, мессенджеры — сквозное шифрование. Ключи терять нельзя.|техника шифрование
Что такое сервер|Компьютер, который отвечает на запросы других. Домашний роутер тоже мини-сервер. Серверы держат в дата-центрах с питанием и охлаждением.|техника сервер
Что такое API простыми словами|Набор правил, по которым программы общаются между собой. Приложение погоды берёт данные через API сервиса. Ключ API — пароль доступа, его не публикуют.|техника api программа
Что такое опенсорс|Код открыт, его можно читать и менять по лицензии. Открытость не значит «всё разрешено». Многие крупные проекты живут на опенсорсе.|техника опенсорс код лицензия
Как проверить факт в интернете|Ищите первоисточник, сверяйте с двумя независимыми источниками. Смотрите дату. Перепроверяйте цитаты и цифры. Не пересылайте без проверки.|интернет факты проверка
Как отличить фейк-новость|Громкий заголовок, отсутствие автора и даты, призыв «срочно перешли», эмоции вместо фактов. Ищите оригинал и первоисточник.|интернет фейк новости
Как защитить личные данные|Не публикуйте паспорт, адрес и номера. Разные пароли на все сервисы. Проверяйте доступ приложений. Удаляйте старые аккаунты.|интернет данные приватность
