## Как это работает в ответах

1. Вопрос проходит через лёгкий стеммер (русские окончания) и взвешивание редких слов.
2. Тема выбирается, только если покрывает больше половины «веса» вопроса и совпала по тегам или названию.
3. Если совпадения нет — Искра честно отвечает сама через бесплатный движок, а не выдаёт случайную тему.
4. Болтовня («привет, как дела», «спасибо») тему не вытягивает — это отдельно проверяется тестом.

Примеры, которые работают: «как работают нейросети» → нейросети (раньше попадало на «задачи на работу»),
«как справиться со стрессом» → стресс, «теорема виета» → теорема Виета, «что такое моль» → моль и молярная масса.

## Как пополнить базу

1. Открой `index.html`, найди `const KNOWLEDGE_PACK`.
2. Добавь объект в `items`:

```json
{
  "id": "math-novaya-tema",
  "title": "Название темы",
  "tags": "ключевые слова через пробел — по ним идёт поиск",
  "text": "Конспект: 1–4 предложения, факты и формулы."
}
```

3. `id` начинается с префикса раздела (`ru-`, `math-`, `phys-`, `chem-`, `bio-`, `hist-`, `geo-`, `en-`, `inf-`,
   `lit-`, `obsh-`, `astro-`, `psy-`, `life-`, `safe-`, `health-`, `job-`, `skill-`, `ai-`, `ege-`, `art-`, `music-`,
   `fin-`, `blend-`, `chess-`, `draw-`, `de-`, `zh-`, `photo-`, `auto-`, `garden-`, `cook-`,
   `sport-`, `eco-`, `travel-`, `tech-`, `nature-`, `code-`, `bug-`, `lang-`),
   иначе тема попадёт в «Прочее». Префикс — только латинские буквы (тест это проверяет).
4. Запусти `npm test` — он проверит дубли, длину текста, число тегов и то, что каждая тема находится по названию.

## Кому и как Искра объясняет

Учебная часть Искры — не только 811 конспектов, но и правила ответа под собеседника
(они в `MASTERY_RULE` внутри `index.html`):

| Кто спрашивает | Как отвечает |
|---|---|
| Школьник 5–9 класс | короткие шаги, простой язык, один пример, вопрос на проверку |
| Старшеклассник | разбор по критериям ОГЭ/ЕГЭ, ловушки, оформление бланка, сверка с fipi.ru |
| Студент | план → тезис → аргумент → вывод, конспект, ГОСТ, источники, подготовка к сессии |
| Программист | рабочий код, версии и зависимости, крайние случаи, объяснение ключевых строк |
| Родитель | что делать сейчас по шагам, как объяснить ребёнку, без нотаций; здоровье — к врачу |
| Взрослый с бытовым вопросом | порядок действий, куда идти, какие документы, где проверить норму |

Про суммы, ставки, сроки и проходные баллы Искра говорит «примерно, на 2026 год» и называет,
где сверить: Госуслуги, сайт школы, fipi.ru, сайт вуза, ФНС, банк. Номера законов и размеры
выплат не выдумываются.
