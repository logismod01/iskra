# Почему сайта нет и как его получить за 3 минуты

## Что я проверила прямо сейчас (факты)

- Репозиторий `logismod01/iskra` существует, ветка `main`.
- **GitHub Pages не включён**: запрос к настройкам Pages возвращает «Not Found» — то есть сайт никогда не публиковался.
- Файлы лежат по пути `iskra_II/ai-app/...`, а **в корне репозитория нет `index.html`**.
  Даже если включить Pages, по адресу `https://logismod01.github.io/iskra/` будет список файлов, а не приложение.

Вывод: файлы загружены, но **не туда, куда смотрит GitHub Pages**, и сама публикация не включена.

## Как исправить (по шагам, без терминала)

### Шаг 1. Положить один файл в корень
1. Открой `https://github.com/logismod01/iskra`
2. Нажми **Add file** → **Upload files**
3. Перетащи файл `iskra-site/index.html` (он лежит в этой папке рядом с этим файлом).
   Важно: имя должно остаться `index.html`, **без** вложенной папки.
4. Внизу нажми зелёную кнопку **Commit changes**

Проверка: на главной странице репозитория теперь видны `README.md`, `index.html`, `iskra_II/`.

### Шаг 2. Включить Pages
1. Открой `https://github.com/logismod01/iskra/settings/pages`
2. Блок **Build and deployment**
3. **Source**: выбери **Deploy from a branch**
4. **Branch**: выбери **main**, справа папку **/ (root)**
5. Нажми **Save**
6. Подожди 1–2 минуты и обнови страницу — сверху появится «Your site is live at …»

### Шаг 3. Открыть сайт
Адрес: **https://logismod01.github.io/iskra/**

Если через 3 минуты всё ещё 404 — обнови `.../settings/pages`, там будет статус сборки:
- «Your site is live» → сайт работает;
- «Queued / Building» → подожди ещё минуту;
- ошибка → почти всегда значит, что `index.html` не в корне.

### Как проверить, что это именно наша сборка
На сайте сверху слева должно быть имя **Искра**, а в ⚙ внизу — кнопка **Правила**.
Если видишь просто текст `Искра` на белом фоне — открылся `README.md`, значит Pages смотрит не туда.

## Убрать мусор из репозитория (по желанию, 30 секунд)
1. Открой `https://github.com/logismod01/iskra/tree/main/iskra_II`
2. Справа сверху **⋯** (три точки) → **Delete directory** → **Commit changes**

В корне останутся: `README.md`, `index.html` — этого достаточно для работы сайта.

- Мой доступ к GitHub в этой сессии — **только чтение публичных данных**. Инструмент с правами записи не подключён (я проверяла — он недоступен).
- Пароль и код из СМС я не спрашиваю и не храню: это небезопасно.

**Если очень нужно, чтобы загружала я:** можно выпустить *personal access token* с правом только на этот репозиторий (Settings → Developer settings → Personal access tokens → Fine-grained tokens → Repository access: только `iskra`, Permissions: Contents — Read and write). Но токен = ключ от репозитория, поэтому я рекомендую ручной путь выше: он занимает 3 минуты и ничего не раскрывает.
