# Вариант 2 — полная версия (папка ai-app, 9 файлов)

Тут больше файлов, но потом удобнее править.

1. Открой `https://github.com/logismod01/iskra/upload/main`
2. Открой у себя папку `ai-app` и **выдели её содержимое** (Ctrl+A), потом перетащи в браузер
   ⚠️ Тащи **файлы**, а не саму папку — иначе сайт окажется в подпапке и не заработает
3. **Commit changes**

**А папку `.github` залить так нельзя** — Windows и macOS её просто не показывают. Поэтому workflow создаём руками:

1. На странице репозитория нажми **Add file** → **Create new file**
2. В поле имени файла впиши целиком, с точками и слэшами:
   ```
   .github/workflows/pages.yml
   ```
   GitHub сам создаст папки по этим слэшам
3. В большое поле вставь содержимое файла `ai-app/.github/workflows/pages.yml` (открой его блокнотом и скопируй)
4. Внизу **Commit changes**

# 🔧 Включаем сайт (обязательно, иначе будет 404)

**Я раньше советовал через Actions — но раз папку `.github` залить сложно, проще через ветку. Результат тот же, а кнопок меньше.**

1. В репозитории сверху: **Settings**
2. В левом меню: **Pages**
3. В блоке **Build and deployment** → **Source**: выбери **`Deploy from a branch`**
   *(если там уже стоит «GitHub Actions» — переключи на «Deploy from a branch»)*
4. Ниже появятся два выпадающих списка:
   - **Branch**: `main`
   - папка: **`/ (root)`**
5. Нажми **Save**
6. Подожди **1–3 минуты** и обнови страницу — сверху появится зелёная плашка:

> Your site is live at **https://logismod01.github.io/iskra/**

**Вот твой адрес:** `https://logismod01.github.io/iskra/`

Открывай — там уже твой ИИ. С телефона тоже работает.

# Что смотреть после открытия

1. Нажми **⚙** справа сверху
2. Провайдер → **Groq** (не «Свой URL»! это была причина ошибки 405)
3. Вставь ключ Groq (`gsk_...`)
4. Нажми **«Проверить подключение»** → должно быть зелёное **«Работает ✓»**
5. Напиши «привет»

# Если что-то не так

| Что видишь | Что делать |
|---|---|
| Открывается 404 | Pages не включён или выбран не тот Source. Settings → Pages → **Deploy from a branch** → main → `/ (root)` → Save |
| «There was an error» при загрузке файла | Слишком большой файл (лимит 25 МБ) или плохое соединение. Попробуй ещё раз |
| Файл залился в подпапку (`iskra/index.html`) | Открой файл → карандаш → в имени убери `iskra/` … проще удалить и залить заново с корня |
| Сайт открылся, но чёрный экран | Открой консоль (F12) и скинь мне ошибку — разберём |
| Ошибка 405 при сообщении | ⚙ → провайдер **Groq**, не «Свой URL» |
| Обновил файлы, а сайт старый | Ctrl+Shift+R (жёсткое обновление). Ещё подожди минуту, GitHub собирает не мгновенно |

# Как обновлять потом

**Вариант 1 (один файл):** скачал новый `index.html` → на GitHub открой этот файл → карандаш → **удали всё** → вставь новое → Commit. Или просто перезалей через Upload files (GitHub предложит заменить).

**Вариант 2 (полная версия):** **Add file → Upload files** → перетащи изменившиеся файлы → Commit. GitHub спросит «заменить?» — да.
