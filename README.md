# Искра

Живой сайт: **https://logismod01.github.io/iskra/**

## Что это
ИИ-ассистент «Искра» — женского рода, работает прямо в браузере: сайт и приложение (PWA).
Файл `index.html` — вся сборка целиком: разметка, код и стили внутри одного файла.

## Что умеет
- Чат, учёба, код, тексты, картинки, решение задач, домашка
- Версии: «Бесплатная» (русский и английский) и «Искра Pro» (любые языки, свободный стиль)
- **Доступ по ключу**: код клиента навсегда + ключ на 24 часа, привязанный к нему. Подробно — [`ДОСТУП-ПО-КЛЮЧУ.md`](ДОСТУП-ПО-КЛЮЧУ.md), серверная часть — [`supabase/iskra-access.sql`](supabase/iskra-access.sql)
- Стиль общения: обычный, душевный, женский, мужской
- Режимы у поля ввода: 🧠 «Глубокое мышление» и ⚡ «Риск» (очень быстро, возможны ошибки)
- Страница правил: ⚙ → «Правила»
- Провайдеры: **Puter · 500+** (вход по желанию — без входа Искра сама отвечает бесплатным движком), «Без ключа», Groq, OpenRouter, свой URL
- Проверка: ⚙ → «Проверить ИИ» — живой запрос выбранной модели
- Языки кода: 23 языка, распознаются автоматически, если не указаны

## Ключи за 24 часа (коротко)
1. У пользователя есть код клиента вида `123456-AB12CD-orange` — он постоянный.
2. Пользователь присылает код в Telegram, владелец выдаёт ключ `ISKRA-24-XXXX-XXXX-XXXX`.
3. Ключ активируется один раз, Pro включается на 24 часа с момента активации.
4. Владелец выдаёт ключи в консоли `/console`: `secret <пароль>`, затем `key24 <код> [название]`.

Если сервер Supabase ещё не настроен, экран ключа честно об этом скажет, а офлайн-ключи
`ISKRA-L-…` будут работать и без него.

## Обновление сайта
1. Заменить `index.html` в корне (upload / API)
2. GitHub Pages обновится за 1–2 минуты
3. Проверка: на сайте в ⚙ должны быть «Версия» и провайдер «Puter · 500+»
