# Искра

Живой сайт: **https://logismod01.github.io/iskra/**

## Что это
ИИ-ассистент «Искра» — женского рода, работает прямо в браузере: сайт и приложение (PWA).
Файл `index.html` — вся сборка целиком: разметка, код и стили внутри одного файла.

## Что умеет
- Чат, учёба, код, тексты, картинки, решение задач, домашка
- Версии: «Бесплатная» (русский и английский) и «Искра Pro» (любые языки, свободный стиль)
- **Доступ по ключу**: код клиента навсегда + четыре тарифа Pro — **24 часа 99 ₽ · месяц 450 ₽ ·
  год 3490 ₽ · навсегда 7990 ₽** (цены меняются командой `price` без правки кода). Подробно —
  [`ДОСТУП-ПО-КЛЮЧУ.md`](ДОСТУП-ПО-КЛЮЧУ.md), серверная часть — [`supabase/iskra-access.sql`](supabase/iskra-access.sql)
- Стиль общения: обычный, душевный, женский, мужской
- Режимы у поля ввода: 🧠 «Глубокое мышление» и ⚡ «Риск» (очень быстро, возможны ошибки)
- Страница правил: ⚙ → «Правила»
- Провайдеры: **Puter · 500+** (вход по желанию — без входа Искра сама отвечает бесплатным движком), «Без ключа», Groq, OpenRouter, свой URL
- Проверка: ⚙ → «Проверить ИИ» — живой запрос выбранной модели
- Языки кода: 23 языка, распознаются автоматически, если не указаны
- **База знаний — 463 темы** (`version 3`, 22 папки): русский, математика, физика, химия, биология, история,
  география, английский, информатика, литература, общество и право, астрономия, искусство и музыка, психология,
  быт и здоровье, учёба и работа, а также **шахматы, финансы, 3D и Blender, черчение, немецкий, китайский,
  фотография, авто, дом и сад, кухня**. Открывается в ⚙ → «Мои знания»: папки, поиск, «Спросить Искру».
  Что именно выучено — [`БАЗА-ЗНАНИЙ.md`](БАЗА-ЗНАНИЙ.md)
- **3D-мастерская (Pro)**: фигуры по параметрам (куб, сфера, цилиндр, конус, тор, пирамида, шестерня,
  звезда, ваза, тарелка) — превью с вращением, скачивание `.obj` и готового скрипта для Blender.
  Кнопка с кубиком в панели инструментов у поля ввода
- **Качество картинок (Pro)**: пресеты стиля, формата и детализации; Flux первым, затем gpt-image-2 через Puter
- **Видео**: сначала Puter (Wan 2.7, 10 с), запасной — открытая LTX-Video, честная пометка о качестве

## Тарифы и ключи (коротко)
1. У пользователя есть код клиента вида `123456-AB12CD-orange` — он постоянный.
2. Пользователь присылает код в Telegram, выбирает тариф и оплачивает.
3. Владелец выдаёт ключ `ISKRA-24-XXXX-XXXX-XXXX` на нужный тариф.
4. Ключ активируется один раз, Pro включается с момента активации.
5. Владелец выдаёт ключи в консоли `/console`: `secret <пароль>`, затем `key <код> month` (или `day`/`year`/`forever`).

| Тариф | Цена | Срок |
|---|---:|---|
| 24 часа | 99 ₽ | 24 ч |
| Месяц | 450 ₽ | 30 дней |
| Год | 3490 ₽ | 365 дней |
| Навсегда | 7990 ₽ | без срока |

Цены меняются в консоли: `price month 590` или `prices 99 590 3990 8990`; посмотреть — `plans`.

Если сервер Supabase ещё не настроен, экран ключа честно об этом скажет, а офлайн-ключи
`ISKRA-L-…` будут работать и без него.

## Встроенная база знаний
- 463 конспекта внутри `index.html` — без интернета и без ключей.
- Поиск: лёгкий стеммер + вес редких слов (IDF). «Как работают нейросети» находит нейросети,
  а не «задачи на работу»; болтовня («привет, как дела») тему не вытягивает.
- Браузер в «Мои знания»: 22 папки, поиск, раскрытие конспекта, кнопки «Спросить Искру» и «Выучить глубже».
- Команды в `/console`: `kb <запрос>` — поиск по базе, `kb-stats` — сколько тем по разделам.
- Дополнить базу: добавить объект `{id, title, tags, text}` в `KNOWLEDGE_PACK.items`
  (первые 4 буквы `id` задают папку: `math-`, `ru-`, `phys-`…), затем `npm test`.
- Тесты: `tests/smoke.test.mjs` проверяет, что база не меньше 300 тем (сейчас 463), каждая тема находится
  по своему названию, 73 живых вопроса ведут в нужную тему и болтовня не даёт ложных срабатываний.

## Обновление сайта
1. Заменить `index.html` в корне (upload / API)
2. GitHub Pages обновится за 1–2 минуты
3. Проверка: на сайте в ⚙ должны быть «Версия» и провайдер «Puter · 500+»
