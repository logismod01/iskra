# Искра

Живой сайт: **https://logismod01.github.io/iskra/**

## Что это
ИИ-ассистент «Искра» — женского рода, работает прямо в браузере: сайт и приложение (PWA).
Файл `index.html` — вся сборка целиком: разметка, код и стили внутри одного файла.

## Что умеет
- Чат, учёба, код, тексты, картинки, решение задач, домашка
- Версии: «Бесплатная» (русский и английский) и «Искра Pro» (любые языки, свободный стиль)
- Стиль общения: обычный, душевный, женский, мужской
- Режимы у поля ввода: 🧠 «Глубокое мышление» и ⚡ «Риск» (очень быстро, возможны ошибки)
- Страница правил: ⚙ → «Правила»
- Провайдеры: **Puter · 500+** (бесплатно, без наших ключей), «Без ключа» (1 ответ в 30 секунд), Groq, OpenRouter, свой URL
- Языки кода: 23 языка, распознаются автоматически, если не указаны

## Обновление сайта
1. Заменить `index.html` в корне (upload / API)
2. GitHub Pages обновится за 1–2 минуты
3. Проверка: на сайте в ⚙ должны быть «Версия» и провайдер «Puter · 500+»
